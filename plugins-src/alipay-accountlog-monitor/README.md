# 支付宝商家账单监控（手动配置）

这是一个可选安装的 CXPAY 支付通道插件。它展示用户配置的固定支付宝收款码，平台每 15 秒通过支付宝开放平台账单接口重叠读取最近十分钟的收入流水，再交给 CXPAY 既有的金额匹配、幂等和人工复核流程。

## 边界

- 不创建支付宝官方支付订单，不改变 CXPAY 个人收款码主流程。
- 不上传 Cookie，不提供“免 CK”或代申请应用能力。
- 必须由用户自行在支付宝开放平台取得 AppID、RSA2 应用私钥、支付宝公钥和相应账单查询权限。
- 插件默认不安装、不启用；安装后才会出现在通道列表。

## 配置

1. 上传或安装本插件。
2. 新建“支付宝商家账单（手动配置）”通道。
3. 填入收款码内容、AppID、应用私钥和支付宝公钥。
4. 启用通道，并确认定时进程正常运行。

同一流水会以 `通道 ID + alipay_order_no` 去重。轮询结果无法唯一匹配订单时会进入人工复核，不会冒险核销。
