========================================================================

【环境要求】
• 推荐系统：CentOS 7+ / Ubuntu 20.04+ / Debian 11+（安装宝塔面板）
• PHP 版本：PHP 8.1 或 PHP 8.2（需安装扩展：pdo_mysql, redis, bcmath, curl）
• 数据库：MySQL 5.7 或 8.0
• 缓存服务：Redis 5.0+

------------------------------------------------------------------------
【极简安装步骤（只需 3 步）】
------------------------------------------------------------------------

第一步：创建站点与上传源码
  1. 在宝塔面板【网站】中新建一个站点（填写您的域名，如：pay.yourdomain.com，PHP 版本选择 8.1 或 8.2）。
  2. 进入该网站根目录，上传本源码压缩包并一键【解压】到根目录下。
  3. 【网站运行目录设置】：
     • 点击该站点右侧【设置】→【网站目录】；
     • 运行目录选择：/public 并点击保存。
  4. 【配置 SSL 证书（必需）】：
     • 点击该站点右侧【设置】→【SSL】；
     • 选择【Let's Encrypt】点击申请免费证书，成功后开启【强制 HTTPS】（支付网关与收银台安全通信必需）。


第二步：一键全自动安装（推荐）
  1. 在宝塔面板进入网站根目录，点击上方的【终端】（Terminal）。
  2. 复制并执行以下命令：
     bash setup.sh
  3. 按照屏幕中文提示依次输入：您的域名、数据库账号密码、Redis 配置及初始管理员账号密码，脚本将自动完成所有环境配置与进程启动。

  ★ 备用图形化向导安装：
     1. 如果不想用终端运行脚本，可在浏览器中直接打开：http://你的域名/install 进行可视化向导配置。
     2. 【重要注意】：网页向导完成数据库配置后，由于受限 Web 环境无法自动注册系统守护服务，必须进入宝塔终端手动执行一次启动命令：
        php start.php start -d
        （或执行：systemctl restart cxpay-runtime）
        网站常驻服务才能正式运行起来！


第三步：登录管理后台
  • 管理员后台地址：http://你的域名/admin_login.html
  • 商户登录地址：  http://你的域名/merchant_login.html

------------------------------------------------------------------------
【常用日常运维命令】
------------------------------------------------------------------------
• 重启服务（修改配置或更新后执行）：
  php start.php reload
  或
  systemctl restart cxpay-runtime

• 查看服务运行状态：
  php start.php status

• 停止服务：
  php start.php stop
