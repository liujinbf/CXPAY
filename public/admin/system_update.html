    🟣 宝塔面板 · 自动定时更新配置 (总控端开发者专用)

    在宝塔面板 → 计划任务 → 添加 Shell 脚本，设置为每天凌晨执行：

    #!/bin/bash # 修改为你的实际路径 APP_DIR="/www/wwwroot/你的域名" PHP_BIN="/www/server/php/81/bin/php" DB_NAME="cxpay" DB_USER="root" DB_PASS="你的数据库密码" export DB_NAME DB_USER DB_PASS bash ${APP_DIR}/update.sh >> ${APP_DIR}/runtime/cron_update.log 2>&1
    执行周期每天 03:00 自动检查更新 注意有更新时才执行，无更新自动跳过
