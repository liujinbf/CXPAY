签名与回调说明

签名算法： MD5。待签名参数按键名 ksort 升序，拼成 k=v&k=v（去除 sign/sign_type 及空值），末尾拼接商户密钥 KEY，再 md5() 得 sign。

下单参数： pid (商户PID)、type (alipay/wxpay/qqpay)、out_trade_no (商户订单号)、name (商品名)、money (金额元)、notify_url (异步回调)、return_url (同步跳转)、sign。

异步通知： 支付成功后系统以 POST 通知你的 notify_url，携带 trade_status=TRADE_SUCCESS 及 sign；你的服务器验签通过后需直接输出原样字符串 success。
