## 🟢 微信扫码授权/登录服务 (WeChat Auth Service)

```
                 +-----------------------------------+
                 |   微信开放平台 (open.weixin.qq)   |
                 +-----------------------------------+
                                   │
                                   ▼
                 +-----------------------------------+
                 |       WeChatAuthService.php       |
                 | (生成 qrconnect 扫码链接/轮询 code) |
                 +-----------------------------------+
                                   │
                                   ▼
                 +-----------------------------------+
                 |    返回 OpenID / UnionID 并绑定   |
                 |      (/api/cloud/wx_login_qr)     |
                 +-----------------------------------+
```

1. **微信扫码授权服务 (`WeChatAuthService.php`)**：封装了微信开放平台网页应用 OAuth 2.0 扫码登录。
2. **API 路由**：`/api/cloud/wx_login_qr` 与 `/api/cloud/poll_wx_login`。
